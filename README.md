# 26BCE11282_MINI_BANK

## VIT BANK 

## Overview of the project 
A Mini Banking System built using Python Programming language. This is a mini bank where users can log in and access different services or create new account.
The system uses Python functions, lists, conditional statements , loops, and user defined modules.

## Feautures

- Account login using account number and password
- Account balance checking
- Cash withdrawal
- Cash deposit
- Account details
- New account creation
- Education loan enquiry and approval
- Home loan enquiry and approval
- Gold loan enquiry and approval
- Loan interest calculation
- Account balance update after transactions (deposit and withdrawl)

## Technology used
