## Title
Mini Bank Account Management System 

## Problem Statement
Develop a banking management system that provides user to create new bank account and old users to avail services like checking account balance , depositing and withdrawing money , loan enquiry and approval,displaying user's theirs account details.

## Scope of the project 
This mini bank account management system has features like basic banking services and also need future improvements as well as .
### Features
- Account login using account number and password
- Account balance checking
- Cash withdrawal
- Cash deposit
- Account details
- New account creation
- Education loan enquiry and approval
- Home loan enquiry and approval
- Gold loan enquiry and approval
- Loan interest calculation
- Account balance update after transactions (deposit and withdrawl)
### Future Improvements

- Add password change feature
- Add transaction history to record deposits, withdrawals, and loans
- Add account deletion feature
- Add EMI calculation for loans instead of only calculating total compound interest
- Add EMI features

## Tareget users 
- Student who are learning python programming language.


## Project Outcome
The final outcome is simple command line banking system that demonstarates the basic features of account management and approve loan.
